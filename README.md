# ลอยกระทงบางทอง
เว็บงานลอยกระทงด้วย Sites / Vinext / Cloudflare D1 โดยไม่ใช้ Higgsfield
## เริ่มใช้งาน
1. เปิดหน้า /admin และเข้าสู่ระบบด้วย ChatGPT
2. สร้างห้องงาน ตั้งชื่องานและสถานที่
3. เปิดจอฉายบนคอมพิวเตอร์ที่ต่อจอใหญ่ และดาวน์โหลด QR แจกผู้ร่วมงาน
4. ผู้ร่วมงานสแกน เลือกกระทง ตกแต่ง วาดลาย พิมพ์ชื่อ และส่งคำอวยพรโดยไม่ต้องเข้าสู่ระบบ หลังส่งจะค้างที่หน้ายืนยันเดิมและบันทึกภาพที่ระลึกได้ หน้าสแกน QR ไม่มีลิงก์ไปหน้าแรกหรือจอฉาย ให้รอชมที่จอใหญ่ของงาน
5. ผู้จัดงานเปิดโหมดอนุมัติก่อนขึ้นจอ ปิดรับคำอวยพร พักการปล่อยกระทง ปรับจังหวะ หรือลบข้อความออกจากจอด้วยปุ่มซ่อน
ข้อความรออนุมัติต้องกดอนุมัติแยก แม้ปิดโหมดตรวจแล้ว กระทงที่ลอยอยู่จะลอยจนจบเมื่อกดพัก; การซ่อนจะนำออกเมื่อจอเชื่อมต่อครั้งถัดไป
## เส้นทาง
- / หน้าแรก
- /studio ห้องทดลองตกแต่ง (ไม่ส่งขึ้นจองาน)
- /display/demo จอสาธิตด้วยข้อความสมมติ ไม่มีการบันทึก
- /admin ห้องควบคุมเจ้าของงาน
- /join/:id หน้าส่งคำอวยพรสาธารณะ
- /display/:id จอฉายจริง
## ข้อมูลและสิทธิ์
บันทึกข้อมูลใน D1 ส่วนกลางจริง แยกห้องด้วย event_id ผู้จัดงานแต่ละคนเข้าถึงเฉพาะห้องที่ตนสร้าง
อาศัย ChatGPT identity headers จาก Sites สำหรับเจ้าของห้อง
Browser storage เก็บรหัสอุปกรณ์ รหัสส่งซ้ำ แบบร่างในแท็บ และคิวของจอ ฐานข้อมูลหลักอยู่ใน D1
จอดึงข้อมูลทุก 2.5 วินาที มีคิวในเครื่องไม่เกิน 36 ใบ อ่านแบบจำกัดขนาดต่อชุด และเก็บตำแหน่ง cursor เพื่อรับกระทงที่เหลือจากฐานข้อมูลตามลำดับ
ชื่อไม่เกิน40และข้อความ140 Unicode codepoints มีการยืนยันก่อนแสดงข้อมูลสาธารณะ, จำกัดความถี่, parameterized SQL และ React escaping
ก่อนวันงานจริงให้ทดสอบ QR อินเทอร์เน็ต จอฉาย และการอนุมัติ ด้วยอุปกรณ์และเครือข่ายหน้างาน ผลทดสอบในเครื่องไม่ใช่การรับรองจำนวนผู้ใช้พร้อมกันบนโฮสต์
## พัฒนา
ใช้ Sites installer/build workflow ตาม skill ปัจจุบัน
Schema: db/schema.ts; สร้าง schema migrations ด้วย pnpm db:generate
ทดสอบ backend: node scripts/integration-check.mjs (ฐานข้อมูลทดสอบชั่วคราว ไม่มีข้อมูลทดสอบใน production)

## ห้องตกแต่งและแสงสี
- 8 รูปทรง: บัว ใบตอง หงส์ หัวใจ จันทร์ ดาว ปราสาท และเรือ
- ของประดับ 20 ชนิด เพิ่มได้ 24 ชิ้น ลาก หมุน ย่อขยาย ทำสำเนา หรือลบได้
- ใช้นิ้วหรือเมาส์วาด เลือกสีและขนาดปากกา ลบเป็นเส้น และย้อนกลับ/ทำซ้ำได้
- วาดได้ 40 เส้น เส้นละไม่เกิน 160 จุด รวมไม่เกิน 2,400 จุด ข้อมูลส่งสูงสุด 64 KiB
- สีหลัก สีรอง สีแสงปรับเองได้ พร้อม 6 ชุดสีและปุ่มสุ่มไอเดีย
- ความเร็วรายกระทง 0.7–1.5 เท่า จำนวนเทียน 0–3 และความเข้มแสงรอบกระทง
- ผู้จัดงานปรับความเร็วรวม 0.5–2 เท่า จังหวะปล่อย 0.6–6 วินาที และแสงสี 4 ธีม
- โคมลอย หิ่งห้อย พลุนุ่มนวล และแสงน้ำเปิดปิดได้แยกกัน เคารพ prefers-reduced-motion
- ความเร็วมีผลกับกระทงที่ปล่อยใหม่ กระทงเดิมจบตามความเร็วเดิม
- เมื่อจอแน่นจะเว้นระยะและรอในคิว ไม่ตัดกระทงที่กำลังแสดงเพื่อแทรกรายการใหม่
- ลายทั้งหมดเก็บเป็นพิกัดและสีที่ตรวจสอบแล้ว ไม่รับ HTML, SVG หรือ URL จากผู้ส่ง
- ผู้จัดงานแตะรูปกระทงในรายการคำอวยพรเพื่อขยายดูภาพวาดก่อนอนุมัติ

## ลูกเล่นสำหรับคืนงาน
- ไฮไลต์ชื่อ คำอวยพร และกระทงใหม่ 5 วินาที พร้อมประกายแสงสั้น ๆ เมื่อเปิดโหมดนี้จะเว้นจังหวะปล่อยอย่างน้อย 5.2 วินาที ปิดได้ในตั้งค่าจอ LED
- หลังส่งกระทงสำเร็จ กด **สร้างภาพที่ระลึก** แล้วดาวน์โหลด PNG 1080 × 1440 พร้อมลายวาด ชื่อ คำอวยพร กรอบทอง และตรา อบต.บางทองจากไฟล์ที่ผู้จัดให้มา ห้องทดลอง /studio ทดลองบันทึกได้เช่นกัน
- ใบรับกระทงล่าสุดเก็บในแท็บเดิม เพื่อกลับมาบันทึกภาพหลังรีเฟรชได้ และมีปุ่มออกแบบกระทงอีกใบ
- ผู้จัดปรับขนาดข้อความ 80–180% ขนาด QR 90–240 px ตำแหน่งทั้ง 4 มุม ระยะเว้นขอบ 0–8% ตราหน่วยงาน และการแสดงเครื่องมือ แล้วกดบันทึก จอฉายรับค่าอัตโนมัติ
- ปุ่มซ่อนเครื่องมือมีผลเฉพาะจอที่กด กด Escape เพื่อแสดงอีกครั้ง หรือแตะมุมขวาล่างที่ตำแหน่งปุ่มแสดงเครื่องมือ
- นับถอยหลัง 10/15/30 วินาที โดยเตรียมจอ 3.5 วินาทีก่อนเริ่ม เลือกกระทงที่อนุมัติล่าสุด 3/6/9/12 ใบ แสดงชุดพร้อมกัน 18 วินาที ใช้เวลาจากเซิร์ฟเวอร์ร่วมกันทุกจอ
- ระหว่างช่วงพิเศษคิวปกติพักและกลับมาทำงานหลังจบ ชุดที่ขึ้นช่วงพิเศษแล้วจะไม่ถูกปล่อยซ้ำจากคิวเดิม กระทงที่ถูกซ่อนจะถูกนำออกเมื่อจอรับข้อมูลครั้งถัดไป
- ผู้จัดยกเลิกช่วงพิเศษได้ ระบบป้องกันการเริ่มทับกันและรองรับการลองคำสั่งเดิมซ้ำหลังเครือข่ายขัดข้อง
- คลังคำอวยพรค้นหาชื่อหรือข้อความ กรองสถานะ ดูหน้าละ 200 รายการ และเปิดย้อนหลังได้หลังปิดรับกระทง
- ปุ่ม **ดาวน์โหลด Excel** รวบรวมทุกหน้าตามตัวกรองเป็น .xlsx จริง มีหัวตารางค้าง ตัวกรอง คอลัมน์แบบกระทง สถานะ วันเวลาประเทศไทย และข้อมูลงานในชีตที่สอง
- การส่งออกตรึงรายการถึงจุดที่เริ่มอ่าน ไม่เพิ่มรายการที่เพิ่งส่งระหว่างดาวน์โหลด ข้อความที่ขึ้นต้นด้วยเครื่องหมายสูตรถูกบันทึกเป็นข้อความ ป้องกันการตีความเป็นสูตร Excel
- คลังและคำสั่งช่วงพิเศษใช้ได้เฉพาะเจ้าของห้องงาน และการเผยแพร่เวอร์ชันนี้ไม่ลบคำอวยพรเก่า

## การตรวจเวอร์ชันนี้
TypeScript และ production build ผ่าน การทดสอบ compiled Worker + D1 ชั่วคราวผ่าน 103 จุด รวมข้อมูลเก่าหลัง migration, แบบกระทง/ลายวาดตรงกับต้นฉบับ, สิทธิ์ผู้จัดงาน, moderation, การส่งพร้อมกัน 100 รายการ, LED, นับถอยหลัง, การสั่งเริ่มพร้อมกันสองหน้า, ยกเลิก, การกรอง และ archive 224 รายการพร้อมแบ่งหน้า
ไฟล์ XLSX ตรวจด้วย ZIP/XML และ openpyxl แยกจากตัวสร้างไฟล์ ผ่านภาษาไทย อีโมจิ การขึ้นบรรทัดใหม่ ข้อความที่ดูเหมือนสูตร ตัวเลข และรูปแบบหัวตาราง
ตรวจการสร้าง PNG ด้วย native Canvas และ SVG renderer พร้อมข้อความยาวสุดและพิกัดกรอบ ภาพวาดและของตกแต่งอยู่ใน SVG ที่ใช้ส่งออก การทดสอบ native Canvas ใช้ฟอนต์ทดแทน จึงยังไม่ยืนยันการจัดวางอักษรไทยในเบราว์เซอร์
การตรวจใช้งานจริงด้วยเบราว์เซอร์ยังไม่ยืนยัน: managed preview รายงานพร้อม แต่ cloud browser เชื่อมต่อไม่สำเร็จ ไม่มีข้อมูลทดสอบถูกส่งเข้า production ผลทดสอบในเครื่องไม่ใช่การรับรองจำนวนผู้ใช้พร้อมกันบนโฮสต์


## หมวดสมจริง 1.1–4.1
- กดหมวด 01–04 แล้วเลือก **แบบปกติ** หรือ **แบบสมจริง** ใต้ชื่อหมวด สลับแต่ละหมวดแยกกันได้ แบบเดิมและค่าที่ปรับไว้ยังอยู่
- **1.1 กระทง:** ภาพสมจริง 6 แบบ ใบตอง บัว ดาวเรือง กล้วยไม้ กะลา และหงส์ มีปุ่มเปิดสมจริงครบ 4 หมวดและสุ่มชุดใหม่โดยเก็บลายวาดไว้
- **2.1 สีสัน:** 8 โทนสี ปรับความสด ความสว่าง ความคมแสงเงา และ 4 ผิววัสดุ (ธรรมชาติ ด้าน หยาดน้ำค้าง ทองคำเปลว) ผิวน้ำค้างและทองใช้กับฐานสมจริง
- **3.1 ของประดับ:** 12 ชนิด ภาพดอกไม้และใบไม้ 6 แบบ พร้อมมุก คริสตัล เทียนขี้ผึ้ง ธูป ทองคำเปลว และมาลัยมุก กรองประเภทหรือวางช่อคู่/พวงล้อมอัตโนมัติ ขยับลำดับหน้า–หลังได้ทั้งแบบปกติและสมจริง
- **4.1 แสง & ลอย:** 6 ชุดแสง ความเข้มเงาสะท้อน ขนาดเปลวเทียน ระลอกน้ำ ควันเทียน ประกาย และการลอย 3 ลักษณะ พร้อมจำนวนเทียนและความเร็ว
- ภาพที่เห็นในห้องแต่ง การส่งขึ้นจอ จอผู้จัด และภาพที่ระลึกใช้แบบเดียวกัน คลังและ Excel แสดงชื่อฐานสมจริง
- ใช้รูปภาพที่เตรียมไว้ในเว็บ ไม่ต้องใช้เครดิต Higgsfield ภาพและรายละเอียดใน [ASSETS.md](ASSETS.md)
- ข้อมูลใหม่อยู่ใน design JSON เดิม ไม่ต้องเปลี่ยน schema และแบบกระทงรุ่นก่อนยังใช้ได้
- `node scripts/realism-check.cjs` ผ่าน 52 จุด: สลับหมวด 16 ชุด, ภาพ 12 ไฟล์, สี/ผิวเปลี่ยนภาพจริง, SVG references, SSR และการฝังภาพที่ระลึก การตรวจภาพ native ใช้ `sharp` จาก primary runtime ถ้ามี
- ตรวจภาพที่ระลึกแบบสมจริงด้วย native Canvas รวมลายวาดและข้อความยาวสุดแล้ว; ตัวอ่าน SVG native ไม่รองรับ WebP จึงแปลงสำเนาเป็น PNG เฉพาะการตรวจภาพ ไม่เปลี่ยนไฟล์ในเว็บ การทดสอบนี้ไม่ใช่การยืนยันการแตะ ลาก หรือดาวน์โหลดบนมือถือจริง


## ความลื่นไหลและการส่งจำนวนมาก
- จอฉายแปลงกระทงเป็นภาพโปร่งใส 480 × 375 ครั้งเดียว แล้วใช้ซ้ำทั้งกระทงลอยและไฮไลต์ จัดคิวแปลงภาพทีละใบและเตรียม 2 ใบถัดไปล่วงหน้า เก็บแคชไม่เกิน 40 ภาพ คืน URL ของภาพเก่าที่ไม่มีผู้ใช้ กรณีสร้างภาพไม่ได้ยังแสดง SVG เดิมได้
- การลอยและไฮไลต์ยังเคลื่อนไหว รายละเอียดเล็กภายในภาพกระทงบนจอฉายเป็นเฟรมคงที่เพื่อลดงานวาด ห้องแต่งและภาพที่ระลึกยังใช้ต้นฉบับครบทุกส่วน
- ลดเอฟเฟกต์ตามขนาดจอ/กำลังเครื่องและการวัดเวลาต่อเฟรม จำกัดกระทงบนจอ 8 / 12 / 18 ใบตามโหมด เมื่อจอเต็มจะรอในฐานข้อมูล ไม่มีการทิ้งเพื่อแทรกใบใหม่
- พักการอ่านคิวและภาพเคลื่อนไหวเมื่อแท็บถูกซ่อน เก็บเวลาไว้ให้กระทงเดิมลอยต่อเมื่อกลับมาที่แท็บ หน้านับถอยหลังอัปเดตเฉพาะเมื่อเลขหรือช่วงเปลี่ยน
- เก็บ checkpoint เฉพาะตำแหน่งคิวและรหัสที่แสดงแล้ว ไม่เขียนลายวาดทั้งคิวลง sessionStorage ทุกครั้ง รองรับ checkpoint รุ่นเดิม และจดรายการช่วงพิเศษที่ยังอยู่ข้างหน้าในคิวไว้ป้องกันขึ้นซ้ำ
- feed อ่านชุดละไม่เกิน 12 ใบในจอฉาย API ตรวจขนาดจาก metadata ก่อนอ่านรูปแบบเต็ม กำหนดงบข้อมูลปกติ 192 KiB ต่อหน้า ช่วงพิเศษยังจำกัด 12 ใบแยกต่างหาก
- เพิ่มดัชนี `feed_event_action_cursor` สำหรับอ่านการเพิ่ม/ซ่อนตามลำดับ Migration 0003 เพิ่มเฉพาะดัชนี ไม่ลบข้อมูล
- จำกัดงานรับกระทงที่ประมวลผลพร้อมกันต่อ Worker isolate ไว้ 24 คำขอ รอได้ 256 คำขอและไม่เกิน 10 วินาที ก่อนตอบให้ลองใหม่ เพื่อไม่ให้แบบที่วาดเต็มรายละเอียดกองในหน่วยความจำ ค่าต่อ isolate นี้ไม่ใช่จำนวนผู้ใช้สูงสุดของเว็บ
